Error codes

Every problem the app reports carries a code like AIR-201. Each notice in the app shows its code and what to do, and the code links straight to its entry on this page. API error responses carry the same codes.

There are 32 codes. Each has its own address, for example docs.airacegp.com/errors#AIR-208. Codes are permanent: a number is never reused for a different problem. Severity is Error when something stopped working, Warning when the app carried on, and Info for good news.

This list is generated from the app's own error registry, so it always matches the codes the app can show.

Settings #

AIR-101

Settings file was unreadable

Warning
What happened
web_config.json was corrupt (a torn write, a crash mid-save, or a hand edit).
What to do
Defaults were loaded and the broken file was kept beside it as web_config.json.corrupt-<time>. Re-apply your settings, or copy values back from that file.
AIR-102

A settings change could not be saved

Error
What happened
web_config.json could not be written: it is open in another program, read-only, or the disk is full.
What to do
Close any editor holding web_config.json, check the folder is writable and has free space, then change the setting again.
AIR-103

Request body was not a JSON object

Warning
What happened
Something sent the app a request whose body was not valid JSON, or was JSON but not an object.
What to do
Only relevant if you script the app: send a JSON object with Content-Type application/json.
AIR-104

A request field was missing or invalid

Warning
What happened
A request named an unknown language, voice or model, or left out a required field.
What to do
Pick the value from the list the app offers. Scripts: check the field against the API docs.

AI providers #

AIR-201

API key rejected

Error
What happened
The provider answered 401/403: the key is wrong, revoked, or lacks access to that model.
What to do
Settings → Secrets: paste a fresh key for that provider (no spaces). Check the provider still offers the model named in your model chain.
AIR-202

Provider rate limit reached

Warning
What happened
The provider answered 429: you used its per-minute or per-day allowance (free tiers are small).
What to do
Wait, or add another provider to your model chain (Settings → AI → Model chain) with Use fallbacks on, so the next one answers.
AIR-203

Provider timed out

Warning
What happened
The provider did not answer in time (driver questions allow 8 s, other calls 60 s). Usually its queue is busy.
What to do
Nothing to do for a one-off. If it keeps happening, move a faster provider up your model chain.
AIR-204

Provider unreachable

Warning
What happened
No connection to the provider: no internet, a firewall, a wrong custom URL, or the provider is down.
What to do
Check your internet connection. For a custom endpoint, check its URL in Settings → AI.
AIR-205

Provider server error

Warning
What happened
The provider answered with a 5xx error: a fault on its side.
What to do
Usually temporary. Keep a second provider in your model chain so the engineer keeps talking.
AIR-206

Unreadable reply from the model

Warning
What happened
The model answered, but not with the JSON the engineer needs (cut off, or prose instead).
What to do
A one-off is harmless: the engineer skips that call. If a model does it often, choose another model in your model chain.
AIR-207

No provider in the model chain can run

Error
What happened
Every entry in the model chain is missing its API key (or the Custom entry has no URL), or the chain is empty.
What to do
Settings → Secrets: add a key for a provider in your chain, or Settings → AI → Model chain: add a provider you have a key for.
AIR-208

Every provider in the model chain failed

Error
What happened
Each provider the engineer tried failed; the notice names the last error's code.
What to do
Look up the code named in the message. Add another provider to your chain, and make sure Use fallbacks is on.
AIR-209

Custom provider is not set up

Error
What happened
The Custom (OpenAI-compatible) provider is missing its URL, model or key.
What to do
Settings → AI: fill in the Custom API endpoint URL and model; Settings → Secrets: add CUSTOM_API_KEY.
AIR-210

An API key was removed

Warning
What happened
A provider's key was cleared in Settings → Secrets.
What to do
That provider is skipped until a key is added again. Nothing to do if you meant it.
AIR-211

Smart routing has no key

Error
What happened
Smart routing is on, but its small-model provider has no API key.
What to do
Add that provider's key in Settings → Secrets, or turn Smart routing off (your question chain answers instead).

Local Ollama #

AIR-251

Ollama is not running

Error
What happened
A model chain entry uses Ollama on this PC, but nothing answers on localhost:11434.
What to do
Start Ollama (the app, or ollama serve in a terminal), or remove the local Ollama entry from your model chain.
AIR-252

Model not installed in Ollama

Warning
What happened
Ollama is running but does not have the model your chain names.
What to do
Press Pull model on the notice, or run ollama pull <model>.
AIR-253

Model download failed

Error
What happened
ollama pull failed: a typo in the model name, no internet, or not enough disk space.
What to do
Check the model name exists on ollama.com, your connection, and free disk space, then pull again.
AIR-254

Ollama is not installed

Error
What happened
The ollama command was not found on this PC.
What to do
Install Ollama from ollama.com, or use a cloud provider in your model chain instead.
AIR-255

Model downloaded

Info
What happened
A model pull finished.
What to do
Nothing to fix. It is used from the next AI call.

Telemetry #

AIR-301

Telemetry reader keeps crashing

Error
What happened
The process that reads the game's telemetry exits repeatedly; the notice shows its last output.
What to do
Make sure the game in Settings → General matches the one you are running. For F1 25, check the UDP port and format in the game's telemetry settings. Restart the app if it persists.

Voice #

AIR-401

Microphone could not be opened

Error
What happened
The selected microphone is unplugged, in exclusive use by another app, or blocked by privacy settings.
What to do
Plug it in, close other apps using it, allow microphone access in Windows privacy settings, or pick another input in Settings → Audio.
AIR-402

Engineer voice failed to load

Error
What happened
The text-to-speech voice model could not be loaded, so the engineer is muted.
What to do
Settings → Voice: pick an installed voice (or install one). If you set PIPER_MODEL_PATH, check the file exists.
AIR-403

Switched to the fast voice

Warning
What happened
This PC could not render the selected voice quickly enough, so calls were arriving late.
What to do
Nothing needed. To go back, pick the voice again in Settings → Voice; close heavy apps first.
AIR-404

Piper voice path is invalid

Error
What happened
PIPER_MODEL_PATH points to a file that is missing or is not a Piper .onnx voice.
What to do
Settings → Secrets: correct the path, or clear it to use the bundled voices.

Web server #

AIR-501

Dashboard port unusable

Error
What happened
The port in Settings → General is in use by another program or not allowed.
What to do
Pick another port (e.g. 6970) in Settings → General. The dashboard keeps running on its previous port meanwhile.
AIR-502

Could not open the dashboard to your network

Error
What happened
LAN access could not bind to all network interfaces (a firewall or another program holds the port).
What to do
LAN access was switched back off. Allow the app through your firewall, or change the port, then turn LAN access on again.
AIR-503

Request refused for safety

Warning
What happened
A request came from another website, a hostname instead of an IP address, or another device for a PC-only action.
What to do
Open the dashboard at the address the app shows (localhost or its IP). Keys and restart only work on the PC running the app.
AIR-504

Not found

Warning
What happened
The page, file or API endpoint asked for does not exist in this version.
What to do
Reload the dashboard. If a bookmark is involved, open the dashboard from its start page.
AIR-505

Download failed

Warning
What happened
Fetching a file from the internet (such as a voice sample) failed.
What to do
Check your internet connection and try again.
AIR-506

Internal error

Error
What happened
The app hit an unexpected error while handling a request.
What to do
Try again. If it repeats, restart the app and report the code with the detail shown.

App #

AIR-901

A background worker crashed and was restarted

Warning
What happened
One of the app's workers (voice, AI, tick, microphone, events) raised an error. It was restarted automatically.
What to do
Nothing needed if it happens once. If it repeats, restart the app and report the code with the worker named.
